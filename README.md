# 热游地图

一个本地运行的城市旅行地图与攻略原型。项目把城市热点卡片、地图交互、收藏与本地攻略生成流程组合在一个轻量 Node.js 服务中，适合用于产品原型、交互演示和本地开发。

## 功能范围

- 展示成都内置城市热点与分类筛选
- 切换其他城市并按城市查询精选地点
- 查看地点详情、收藏地点和生成本地攻略草稿
- 可选接入天气、地点和文本生成服务
- 通过 Node.js 本地服务提供静态文件和 API 代理

项目没有实现账号体系、支付、订单、真实评论后端、实时路线导航或生产级数据审核。页面中的收藏和评论属于浏览器内演示状态。

## 项目结构

- `index.html` 页面结构
- `styles.css` 页面样式和响应式布局
- `app.js` 浏览器端交互、渲染和攻略流程
- `city-hotspots.js` 城市热点数据
- `server.mjs` 本地静态文件服务和可选 API 代理
- `start-site.cmd` Windows 启动脚本
- `docs/usage.md` 使用和配置说明
- `docs/architecture.md` 系统结构和数据流说明

## 环境要求

- Node.js 18 或更高版本
- 现代浏览器
- 可选的外部服务凭证，用于天气、地点和文本生成能力

项目没有安装依赖包，`package.json` 仅提供 `node server.mjs` 启动命令。

## 安装和运行

```powershell
node --version
node server.mjs
```

浏览器打开 <http://127.0.0.1:5173/>。Windows 用户也可以运行 `start-site.cmd`。

## 配置

基础页面和成都内置数据无需密钥即可运行。需要外部服务时，在本地 shell 环境中设置对应变量，再启动服务。不要把真实凭证写入 Git 仓库。

- `PORT` 可选端口，默认 `5173`
- `DEEPSEEK_API_KEY` 可选文本生成服务凭证
- `DEEPSEEK_MODEL` 可选模型名，默认 `deepseek-chat`
- `AMAP_API_KEY` 可选高德天气和地点服务凭证

## 使用示例

1. 运行 `node server.mjs`。
2. 打开首页并切换城市或分类。
3. 点击地点查看详情，将地点加入攻略或收藏。
4. 在攻略区域输入目的地、日期和偏好，生成本地草稿。配置外部服务后，页面会通过本地服务请求实时能力。

## 测试和检查

```powershell
node --check app.js
node --check server.mjs
```

启动服务后可以访问首页并检查浏览器控制台。外部 API 的可用性取决于凭证、配额、网络和第三方服务状态。

## 数据和隐私

仓库只应包含虚构或公开的城市地点信息。用户输入会在启用外部文本生成或地图服务时发送给对应服务，请在部署前补充适用的隐私告知和数据保留规则。不要提交环境变量文件、日志、浏览器缓存或个人路径。

## 已知限制

- 外部服务返回内容需要人工核验，不能作为票价、营业时间或路线的唯一依据。
- 服务面向本机原型使用，未提供账号、权限、限流、审计和生产部署配置。
- 运行时依赖网络访问外部图片和可选 API。
